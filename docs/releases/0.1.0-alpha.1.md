# Chamfer UI 0.1.0-alpha.1

Precision UI for SaaS teams. The first alpha pairs eight original React component families with shared light/dark tokens, English documentation, Storybook specimens, editable Figma foundations, and a working operations dashboard.

The `chamfer-ui` installer copies TypeScript source into an existing React 19 / Tailwind CSS 4 app. You own and can edit that source. It resolves component dependencies, supports dry runs, preserves customized dependencies, and backs up explicitly replaced components.

## Installation

The installer is published on npm:

```sh
npx chamfer-ui@0.1.0-alpha.1 init --css src/index.css
npx chamfer-ui@0.1.0-alpha.1 add button text-field
```

The release also includes a tarball for local installation and a checksum.

## Included

- Button, TextField, Badge, Card, Separator, Skeleton, semantic Table parts, and AppShell.
- Primitive, semantic, and component tokens; self-hosted IBM Plex Latin fonts.
- Local synthetic dashboard data with search, status filtering, sorting, pagination, CSV export, and loading/empty states.
- Figma variants and desktop/mobile compositions in both themes.
- MIT core code, contribution guidance, CI checks, and accessibility guidance.

## Alpha limits

Component APIs may change before 1.0. The dashboard has no backend, authentication, or payment connection. The hosted Figma file currently requires invited access; the repository includes a native import generator for your own file. Figma is a static editable reference with documented spacing/decorative differences from the browser. Automated checks do not replace assistive-technology review. Firefox cannot launch on the current macOS test host; Linux CI includes it but its remote result must be checked after upload.

Chamfer Pro assets, paid templates, checkout, and commercial licensing are future work.
