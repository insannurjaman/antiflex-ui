# antiflex/ui 0.1.0-alpha.2

The complete antiflex/ui source installer includes fifty original component families, shared light/dark tokens, DM Sans, Anybody and Space Mono typography, and independent React 19/Tailwind 4 support.

The executable is `antiflex`; configuration is `antiflex.json`. Defaults are `src/components/antiflex` and `src/styles/antiflex`, with `af-` classes and `--af-` CSS variables. Workspace packages use @antiflex. Native behavior, typed props and component exports remain unchanged.

The alpha is MIT licensed. Download and verify the release artifact, initialize a React/Tailwind project and add components individually or with `antiflex add --all`. Custom source files remain protected; explicit replacement creates backups under `.antiflex/backups`.
