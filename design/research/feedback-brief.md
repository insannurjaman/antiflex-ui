# Feedback and navigation foundation

Date: 2026-10-18. Local extension of Chamfer's established mint/gray system. Read mode in documentation; Operate mode in examples. Preserve identity, typography, token roles, dashboard behavior, and existing public APIs.

Scope: Alert, Avatar, Breadcrumb, Empty, Kbd, Pagination, Progress, Spinner, Tabs, Accordion, Collapsible, Toggle, Toggle Group, Typography, Aspect Ratio. One family per catalog entry; subcomponents are anatomy, not extra inventory. Native markup and authored behavior only. Reuse token layers and source installer.

Contracts: Alert is static unless a consumer requests a live role. Avatar exposes one accessible name with a stable fallback on missing/loading/failed images. Breadcrumb and Pagination are named navigation landmarks and support native links; application pagination uses native buttons. Progress is native, determinate or indeterminate, and requires a name. Spinner is decorative unless named. Tabs use roving focus, horizontal/vertical and RTL arrows, disabled skipping, Home/End, automatic/manual activation, linked panels. Accordion uses heading buttons, single/multiple controlled or uncontrolled values, linked hidden panels, optional arrow navigation, and disabled items. Collapsible has a native button, expanded state, linked hidden content, and focus recovery on close. Toggle has a stable name and aria-pressed; Toggle Group supports independent or exclusive pressed buttons with roving focus without pretending to be a radio group. Typography is semantic recipe CSS, and Aspect Ratio is a container with a positive finite ratio.

Deliverables: source, API pages, useful specimen states, integrated feedback/navigation example, Storybook, tests for behavior and accessible names/relationships, installer consumer, Figma variables/variants with native geometry. Validate mobile/tablet/desktop, light/dark, RTL, long content, and reduced motion. Avoid claiming parity with the full reference catalog or an npm release.
