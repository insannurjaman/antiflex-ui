# Chamfer UI

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

User-approved: React, TypeScript, Tailwind CSS, Next.js documentation, Storybook, pnpm workspace.

## Users

SaaS designers and React developers creating compact operational interfaces.

## Product Purpose

An original design system with matching Figma and code, public documentation, and a reusable component foundation.

## Positioning

Precision UI for SaaS teams. Free core; future Chamfer Pro adds separately licensed Figma assets, blocks, and templates.

## Capabilities and Constraints

Foundation milestone: eight components, tokens, documentation, Storybook, and a responsive dashboard demonstration. Own styling and behavior. No shadcn, Radix, Base UI, or third-party behavior libraries. The local source installer copies editable components into independent React apps. Commerce and public publication are later milestones.

## Brand Commitments

Chamfer UI. Technical and compact. Cool neutrals, restrained cyan, thin borders, IBM Plex Sans and IBM Plex Mono, original chamfered geometric mark.

## Evidence on Hand

Dashboard data is synthetic and must be labeled. No customers, testimonials, revenue, or production benchmarks have been supplied.

## Product Principles

- Keep Figma and code aligned through named tokens.
- Native semantics and keyboard access first.
- Small complete components before breadth.
- Working examples, honest product claims.
